# המערכת של ליה 💜

Hebrew RTL mobile timetable for Lia. Shows daily subjects, teachers and classroom numbers. Supports edits saved on the device.

**Note:** The data was manually transcribed from a photographed timetable and several entries need verification. In particular, room numbers for group-specific lessons may be uncertain. The numbers in parentheses on the source are classroom numbers.

Teachers supplied by the parent: English Gregory (גרגורי), Math Guy (גיא), Lashon Yael (יעל).

To publish, use Settings → Pages → Deploy from branch → main / (root). The expected URL is https://lebrati58.github.io/lia-timetable/.

Edits made on the phone are local to that phone and not synchronized. Never treat this as the school's authoritative schedule.
